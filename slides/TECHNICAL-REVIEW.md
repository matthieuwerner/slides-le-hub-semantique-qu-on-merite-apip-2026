# Revue technique courante

Voir les [contrats et vérifications](../docs/CONFERENCE-VALIDATION.md) pour les invariants testés et les commandes de validation. Voir les [résultats](../docs/results.md) pour les mesures et les méthodes.

Les chemins démontrés sont implémentés : Provider marchand + JoliCode AutoMapper, conversion privée v2, marqueur d’appel natif et suite de tests publique. Le POST renvoie 200 et les identités sont stables au rejeu. Les comparaisons de scénarios indépendants vérifient puis écartent les identifiants propres à chaque scénario. La projection scalaire est configurée, les invariants de risque restent explicites.

Le talk ne promet ni production prête, ni supériorité générale de Go, ni fiabilité mesurée des agents IA. Les fonctionnalités récentes optionnelles restent en réserve. Les notes expliquent les termes, les limites et les objections sans transformer des hypothèses en preuves.
